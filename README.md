# SplitBill frontend

Next.js App Router starter using TypeScript and Tailwind CSS.

From this directory, run `npm install` and then `npm run dev` to start the development server at `http://localhost:3000`.

The current home page is a scaffold. It does not yet call the backend or implement group, expense, split, or balance flows.

## Checks

Run `npm test`, `npm run lint`, and `npm run build`. For the browser smoke test, install Chromium once with `npx playwright install chromium`, then run `npm run test:e2e`. See [testing guidance](docs/TESTING.md) and [source organization](docs/ARCHITECTURE.md).
